# CTK EnrollSys — User Manual

Purpose: Step-by-step instructions for system users (Admin, Registrar, Parent).

[Figures]

## Quick Start
1. Open the app at the provided URL (e.g., https://your-deploy.vercel.app or http://localhost:3000).
2. Sign in with your account. First run creates a default admin (change password immediately).

[Figures]

## User Roles Overview
- Admin: full access — user management, system configuration, reports.
- Registrar: enrollment processing, student records, payments.
- Parent: submit enrollment, upload documents, track status.

## Admin Guide
### 1. Sign in
- Go to Login page, enter credentials. [Figures]

### 2. Dashboard
- View analytics and recent activity. [Figures]

### 3. User Management
- Create user → fill name, email, role → Save. [Figures]

### 4. System Configuration
- Set school year, grade levels, fee structures via Settings → Save. [Figures]

### 5. Reports
- Generate DepEd-compliant reports (SF1, SF2) via Reports → Select filters → Export PDF/Excel. [Figures]

## Registrar Guide
### 1. View Pending Enrollments
- Navigate to Enrollment queue → filter by school year/status. [Figures]

### 2. Review Documents
- Open application → verify uploaded files (PSA, report card, ID) → mark valid/invalid. [Figures]

### 3. Approve or Reject
- Use Approve/Reject buttons, add notes if needed → Confirm. [Figures]

### 4. Create Student Record
- After approval, convert application to student record, assign grade/section. [Figures]

### 5. Payments
- Log manual payments: enter amount, method, reference → Save. [Figures]

## Parent Guide
### 1. Create Account (if required)
- Register with your email → verify via email (if enabled). [Figures]

### 2. Submit Enrollment
- Fill enrollment form → upload required documents (PSA, report card, photo) → Submit. [Figures]

### 3. Track Status
- Go to My Applications → view status and notes → respond to requests for missing documents. [Figures]

### 4. Payment
- View assessed fees in application → follow instructions for payment (offline or recorded manually by registrar). [Figures]

## Common Workflows (Step-by-step)
### Enroll a Student (Parent)
1. Login → Enrollment Form → Fill details → Upload documents → Submit.
2. Registrar reviews → requests corrections or approves.
3. Upon approval, student record is created and parent is notified.

[Figures]

### Run a Report (Admin)
1. Reports → select type and filters → Export.
2. Download PDF/Excel and store as needed.

[Figures]

## Troubleshooting & FAQs
- Forgot password: use "Forgot password" flow or contact Admin.
- File upload errors: ensure file types (PDF/JPG) and size limits are met.
- Missing application: check email confirmation and application list.
