## Training Overview

### Objectives

By the end of training, users will be able to:

1. **Admin Users:**
   - Manage user accounts (create, update, deactivate)
   - Configure school year and fee structures
   - Generate administrative reports
   - Monitor system activity through audit logs

2. **Registrar Users:**
   - Process enrollment applications efficiently
   - Manage student records
   - Log and track payments
   - Generate DepEd-compliant reports

3. **Parent Users:**
   - Create and manage student enrollment applications
   - Upload required enrollment documents correctly
   - Track enrollment status and respond to registrar requests
   - View balances and payment history

### Training Approach

| Method | Description |
|--------|-------------|
| **Hands-On Practice** | Users perform tasks in test environment |
| **Demonstration** | Trainer shows workflow step-by-step |
| **Documentation** | Written guides for reference |
| **Q&A Sessions** | Interactive problem-solving |

### Prerequisites

- Basic computer literacy (can use web browser, email)
- Understanding of current enrollment process
- School-issued email account

## Admin User Training

### Module A1: System Overview (30 minutes)

**Objectives:**
- Understand the purpose and benefits of CTK EnrollSys
- Navigate the admin dashboard
- Identify key modules and features

**Topics Covered:**

| Topic | Duration | Activities |
|-------|----------|------------|
| System introduction | 10 min | Presentation |
| Dashboard walkthrough | 10 min | Guided tour |

**Key Points:**

- Three user types: Admin, Registrar, Parent
- Admin has highest access level
- Dashboard shows real-time enrollment statistics

---

### Module A2: User Management (45 minutes)

**Objectives:**
- Create new user accounts
- Update user information
- Deactivate and reactivate accounts
- Understand role-based permissions

**Topics Covered:**

| Topic | Duration | Activities |
|-------|----------|------------|
| Creating registrar accounts | 15 min | Demo + Practice |
| Editing user profiles | 10 min | Hands-on |
| Account deactivation | 10 min | Demo + Practice |
| Password reset process | 10 min | Demo |

**Step-by-Step: Creating a Registrar Account**

```
1. Go to Admin Dashboard → Users
2. Click "Add New User"
3. Enter email (school email required)
4. Select role: "Registrar"
5. Enter name and contact details
6. Click "Create Account"
7. User receives email with login instructions
```

**Practice Exercise:**
- Create 2 test registrar accounts
- Edit one account's contact information
- Deactivate one account
- Reactivate the account

### Module A3: School Year Configuration (30 minutes)

**Objectives:**
- Create and manage school years
- Set enrollment periods
- Configure grade levels

**Topics Covered:**

| Topic | Duration | Activities |
|-------|----------|------------|
| Creating new school year | 15 min | Demo + Practice |
| Setting enrollment period | 10 min | Hands-on |
| Managing grade levels | 5 min | Demo |

**Step-by-Step: Creating a School Year**

```
1. Go to Admin Dashboard → School Years
2. Click "Create School Year"
3. Enter details:
   - Name: "2024-2025"
   - Start Date: August 5, 2024
   - End Date: May 30, 2025
   - Enrollment Start: March 1, 2024
   - Enrollment End: July 31, 2024
4. Select available grade levels
5. Click "Save"
6. Click "Set as Active" when ready
```

### Module A4: Fee Structure Setup (45 minutes)

**Objectives:**
- Create fee structures for each grade level
- Configure payment options and discounts
- Link fee structures to school year

**Topics Covered:**

| Topic | Duration | Activities |
|-------|----------|------------|
| Understanding fee categories | 10 min | Discussion |
| Creating fee structure | 20 min | Demo + Practice |
| Payment options setup | 10 min | Hands-on |
| Discount configuration | 5 min | Demo |

**Step-by-Step: Creating Fee Structure**

```
1. Go to Admin Dashboard → Fee Structures
2. Select School Year: "2024-2025"
3. Click "Add Fee Structure"
4. Select Grade Level: "Grade 3"
5. Add fee items:
   - Tuition Fee: ₱18,000 (Required)
   - Miscellaneous: ₱5,000 (Required)
   - Books: ₱2,000 (Required)
6. Configure payment options:
   - Annual (5% discount)
   - Semi-Annual (3% discount)
   - Quarterly (no discount)
7. Click "Save Fee Structure"
```

**Practice Exercise:**
- Create fee structures for 3 different grade levels
- Add early bird discount (5%)
- Add sibling discount (10%)

### Module R2: Processing Enrollments (60 minutes)

**Objectives:**
- Review enrollment applications
- Verify uploaded documents
- Approve, reject, or request additional information
- Assess fees for approved enrollments

**Topics Covered:**

| Topic | Duration | Activities |
|-------|----------|------------|
| Enrollment queue management | 10 min | Demo |
| Reviewing applications | 15 min | Hands-on |
| Document verification | 15 min | Practice |
| Approval/Rejection process | 10 min | Demo + Practice |
| Fee assessment | 10 min | Hands-on |

**Step-by-Step: Processing an Enrollment**

```
1. Go to Registrar Dashboard → Enrollments
2. Click on pending application
3. Review student information:
   - Verify name, birthdate, grade level
   - Check previous enrollment (if returning)
4. Verify documents:
   - Click "Documents" tab
   - View each document
   - Mark as "Verified" or "Rejected"
5. If documents need correction:
   - Click "Request Re-upload"
   - Enter reason
   - Parent is notified
6. If all correct:
   - Go to "Fee Assessment" tab
   - Verify fee structure
   - Apply discounts if applicable
   - Click "Approve Enrollment"
7. Add remarks (optional)
8. Click "Confirm Decision"
```

**Practice Exercise:**
- Process 5 enrollment applications
- Approve 3 with verified documents
- Request re-upload for 1 (photo issue)
- Reject 1 with incomplete information

### Module R4: Payment Management (45 minutes)

**Objectives:**
- Log payment transactions
- View payment history and balance
- Handle different payment methods

**Topics Covered:**

| Topic | Duration | Activities |
|-------|----------|------------|
| Logging cash payment | 15 min | Demo + Practice |
| Other payment methods | 10 min | Hands-on |

| Voiding payments | 10 min | Practice |

**Step-by-Step: Logging a Payment**

```
1. Go to Registrar Dashboard → Payments
2. Click "New Payment"
3. Search for student
4. Select enrollment (if multiple)
5. Enter payment details:
   - Amount: ₱6,250.00
   - Payment Method: Cash
   - Description: "First Quarter Payment"
6. Click "Record Payment"
7. System generates receipt number
8. Print or email receipt (optional)
```

**Payment Methods Supported:**

| Method | Additional Info Required |
|--------|-------------------------|
| Cash | None |
| Check | Check number, bank name |
| Bank Transfer | Reference number |
| GCash | Reference number |

**Practice Exercise:**
- Log 3 cash payments
- Log 1 check payment
- View student payment history
- Void a test payment

## Assessment & Certification

### Competency Assessment

After training, users complete practical assessment:

**Admin Assessment Tasks:**
- [ ] Create a new registrar account
- [ ] Set up a school year with enrollment period
- [ ] Create fee structure for Grade 5
- [ ] Generate enrollment summary report
- [ ] Review audit log for specific action

**Registrar Assessment Tasks:**
- [ ] Process 3 enrollment applications (approve, reject, request reupload)
- [ ] Search for student by name and LRN
- [ ] Update student contact information
- [ ] Log 2 payments (cash and check)
- [ ] Generate class list report

**Parent Assessment Tasks:**
- [ ] Create and submit 1 complete enrollment application
- [ ] Upload all required supporting documents
- [ ] Check application status and interpret feedback
- [ ] Respond to a request for document re-upload
- [ ] View assessed fees and payment status

### Passing Criteria

| Criteria | Requirement |
|----------|-------------|
| Task Completion | Complete all tasks |
| Accuracy | No data entry errors |
| Independence | Minimal assistance needed |
| Time | Within expected duration |

### Certification

Upon successful completion:
- Certificate of Completion issued
- User account activated for production
- Added to support communication group
